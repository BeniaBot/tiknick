# 📋 Tik-Nick (טיקניק)

**תוכנת דסקטופ בעברית לניהול ומעקב אחר ניקים (שמות משתמש) בפורומים.**
כל המידע נשמר מקומית במחשב שלך — פרטיות מלאה.

## ✨ יכולות

### 📇 ניהול ניקים
ריכוז שמות משתמש עם פרטים מלאים (שם אמיתי, טלפון, מייל, כתובת, קבוצות, מוניטין, סטטוס, הערות ועוד), בתצוגת טבלה או כרטיסיות. כולל אנשי קשר נוספים, הערות פרטיות, ומחיקה/עריכה מרובה.

### 🔗 זהויות מקושרות
קישור בין ניקים שמייצגים את אותו אדם בפורומים שונים, עם קבוצות זהות טרנזיטיביות.

### 🎖️ מנגנון מקורות ואמינות
כל ערך מיוחס למקור (אני / סריקה / ייבוא) עם דרגת אמינות; הערך האמין ביותר מנצח. סימון ❗ למידע סותר, עם אפשרות לפתרון ידני.

### 🔍 חיפוש וסינון מתקדם
חיפוש מהיר בכל השדות (FTS5), וסינון מרובה-תנאים (למשל: שם מכיל "משה" **וגם** כתובת מכילה "בני ברק") עם פעולות מרובות על התוצאות.

### 🌐 סנכרון מהאינטרנט
סריקת פורומי **NodeBB ו-Discourse** דרך ה-API הרשמי — שליפת פרטים מורחבים, סריקת כל הפורומים ברצף עם דילוג אוטומטי, הגבלת עמודים, ועוגיות התחברות שנשמרות אוטומטית לכל פורום. עשרות פורומים חרדיים מובנים ברשימה.

### 🔎 תצוגת משתמש מאוחדת
הקלדת שם מציגה תצוגה מרוכזת של כל המידע על אותו אדם — כולל מכל הזהויות המקושרות אליו בפורומים השונים.

### 📖 Chazonishnik
ניתוח מעמיק של פעילות משתמש בפורום: פוסטים, לייקים, שעות וימי פעילות, מעריצים מובילים ועוד — בדוח אינטראקטיבי עם גרפים (עובד גם אופליין). אפשר להגביל את מספר הפוסטים. *(קרדיט: cfopuser)*

### 🦨 Stinknik
מציג את **כל** הפוסטים של ניק שקיבלו דיסלייקים — כולל אלה שהפורום לא מציג. *(קרדיט: טופ שבמתמחים)*

### 📤 ייצוא גמיש
ייצוא כל הניקים, רק ניקים עם מידע, או רק ניקים עם מידע שהוספת בעצמך.

### 🗄️ גיבוי, שחזור וסל מחזור
גיבוי מלא של כל המאגר לקובץ אחד בלחיצה, ושחזור ממנו (עם עותק בטיחות אוטומטי). ניקים שנמחקו עוברים לסל מחזור עם "בטל" מיידי ושחזור עד 30 יום. דיאלוג "בריאות המאגר" עם תקינות, גודל וכיווץ.

### 📞 קישורי קשר, העתקה ואקסל
לחיצה על טלפון פותחת וואטסאפ/חיוג, על מייל — שליחה. העתקת שורות נבחרות כטבלה להדבקה באקסל, ייצוא CSV, וייצוא חלקי של הנבחרים או התצוגה הנוכחית. קיצורי מקלדת (Ctrl+F, חיצים, Enter, Delete).

### 🔄 עדכונים
בדיקת עדכונים אוטומטית, ועדכון מלא מתוך התוכנה — בגרסה הניידת וגם בגרסה המותקנת (כל אחת מתעדכנת לאותו סוג).

### 🎨 נוסף
תיוג ניקים (@שם), ייבוא/ייצוא עם מיפוי פורומים, מצבי תצוגה בהירים/כהים, וממשק RTL מלא.

## 🚀 הפעלה מהירה

### הרצה מהמקור
```bash
pip install pywebview
python main.py
```

### בדיקות
```bash
python tests/run_all.py
```

### קימפול ל-EXE עצמאי (גרסה ניידת)
```bash
build.bat
```
הקובץ `dist\TikNick.exe` ירוץ על כל Windows 10/11 **ללא התקנת Python**.

### בניית אינסטולר
```bash
build_installer.bat
```
מפיק `dist\TikNick-Setup.exe` — התקנה למשתמש (ללא הרשאות מנהל), עם קיצורי דרך ועדכון עצמי. דורש [Inno Setup 6](https://jrsoftware.org/isdl.php).

## 🏗️ ארכיטקטורה

Tik-Nick בנוי על **PyWebView** — הממשק (הכפתורים, הטבלה, החלונות) הוא למעשה HTML/CSS/JS שרץ בחלון מוסווה, והלוגיקה (מסד נתונים, סריקה) היא פייתון. השניים מדברים דרך גשר API. גישה זהה לזו של Discord ו-VS Code.

```
tiknick/
├── main.py           # Backend + PyWebView + API
├── database.py       # לוגיקת SQLite ומנגנון המקורות
├── scraper.py        # סריקת פורומי NodeBB
├── chazonishnik.py   # ניתוח פעילות משתמש
├── stinknik.py       # איתור דיסלייקים
├── web/
│   ├── index.html    # מבנה הממשק
│   ├── style.css     # עיצוב (כהה/בהיר)
│   └── app.js        # לוגיקת הממשק
├── TikNick.spec      # הגדרות בנייה ל-PyInstaller
└── build.bat         # קימפול בלחיצה אחת
```
